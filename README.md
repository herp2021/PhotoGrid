# PhotoGrid

A simple browser-based tool for creating photo grids and exporting them for print or sharing.

## Features

- Upload multiple photos and reorder them by dragging thumbnails.
- Choose the number of rows and columns.
- Adjust gaps, borders, border color, and rounded corners.
- Choose a background color.
- Use Square, 4x6, 5x7, 8x10, Instagram, A3, A4, or A5 sizes.
- Switch between portrait and landscape orientation.
- Shuffle or clear the selected photos.
- Export each grid as a separate JPG file.
- Export all grids as pages in one PDF.

## Usage

Open `index.HTML` in a modern browser, upload your photos, adjust the grid, and download the JPGs or PDF.

The default format is portrait A4. Photos are placed once per grid and continue onto additional JPG files or PDF pages until all photos are used.
